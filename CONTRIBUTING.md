# Contributing

Please submit skills that are useful, reusable, and clearly documented.

## Submission Criteria

- The repository is public and actively maintained.
- It contains a `SKILL.md`, or clearly documents a reusable skill workflow.
- Its README explains the intended agent, installation, and usage.
- It is relevant to AI coding agents and is not a thin prompt collection.
- It has a clear license and does not distribute secrets or unsafe defaults.

## Pull Requests

Open a pull request with the repository URL, its category, supported agents, and a short reason it belongs in this collection. The automated collector manages `data/skills.json`; do not manually edit generated pages unless fixing the generator.
